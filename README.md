# 602-Neocities

Source for my Neocities site: https://602.neocities.org

- `index.html`: home page (Win98-style windows, music player, links, buttons)
- `pages/`: other pages (art)
- `js/wizard3d.js`: the spinning 3D logo
- `buttons/`: 88x31 buttons. Feel free to link to them!
- `button-preview.html`: local page used to design and export the buttons (not uploaded)
- `deploy.sh`: uploads the site using the Neocities API (needs `NEOCITIES_API_KEY`)
